# Hotel Booking Demand Analysis

An end-to-end data analytics project investigating hotel booking cancellations, customer behaviour, booking demand, and hotel performance using SQL, Python, and Power BI.

## 🎯 Business Problem

Why are hotel bookings being cancelled, and what factors can hotels use to improve booking stability and revenue performance?

## 🛠️ Tools

- SQL
- Python
- Pandas
- Matplotlib
- Seaborn
- SciPy
- Power BI
- Jupyter Notebook

## 📊 Dataset

The cleaned dataset contains **87,367 hotel bookings and 32 variables**, covering:

- Booking and cancellation information
- Hotel type
- Lead time
- Customer type
- Market segment
- Deposit type
- ADR
- Stay duration
- Special requests

## 🔎 Key Findings

- **City Hotels** had a higher cancellation rate than Resort Hotels.
- **Longer lead times** were associated with higher cancellation rates.
- **Repeat guests** were significantly less likely to cancel than new guests.
- **Resort Hotels** had lower ADR but longer average stays, contributing to higher revenue per booking.
- Booking demand showed clear **seasonal patterns**.

## 📈 Power BI Dashboard

The project includes a three-page interactive dashboard:

1. **Hotel Booking Overview**
2. **Cancellation Analysis**
3. **Revenue & Hotel Performance**

## 💡 Recommendations

- Strengthen cancellation management for high-risk bookings.
- Develop customer loyalty strategies to encourage repeat bookings.
- Maintain engagement with guests who book far in advance.
- Promote longer stays where appropriate.
- Use seasonal demand patterns to improve pricing, staffing, and marketing decisions.
